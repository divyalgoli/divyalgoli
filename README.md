An AI web app that **explains code line by line in English and Hinglish**, made for students.

- 📖 Line-by-line explanations with a beginner tip for each line
- ⏱️ Time and space complexity, 🔁 dry run, 🗺️ flowchart and algorithm generation
- 🎓 Viva questions and MCQs, 📽️ presentation mode, 📄 PDF export
